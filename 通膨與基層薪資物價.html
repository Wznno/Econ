範疇領域 AREMOS 搜尋關鍵字 代碼 / 變數名 資料頻率 研究用途與說明
政策核心 基本工資、每小時基本工資 MW_MONTH / MW_HOUR 月 (Monthly) 勞動部公告之全時勞工月薪與時薪法定最低標準。

基層薪資 住宿及餐飲業受僱員工總薪資 WA_HOTEL_CATER 月 (Monthly) 包含經常性與非經常性薪資，反映邊際低薪受僱者的真實所得。

控制變數 進口物價指數（農工原料） IPI_AGRI_RAW 月 (Monthly) 控管國際食材與大宗物資價格衝擊對餐飲業成本之影響。
控制變數 實質 GDP 成長率 / 私人消費 GDP_R_Q / CONS_R_Q 季 (Quarterly) 總體經濟總需求控制變數，需透過內插法轉為月資料或配合季模型。

外生政策衝擊 (Policy Shock)

法定最低工資 (Minimum Wage) 調升

月薪 / 時薪標準提高 $\rightarrow$ 衝擊邊際低薪受僱勞工比例極高之住宿餐飲業

管道 A: 成本推升

勞動邊際成本 ($MC$) 上升

  • 餐飲業邊際低薪勞工佔比極高
  • 短期內固定資本無法快速替代
  • 商家將成本快速轉嫁至餐點定價
外食費 CPI ($P_{out}$) 快速推升
管道 B: 所得與需求擴張

名目可支配所得增加

  • 低薪族群之邊際消費傾向 (MPC) 較高
  • 基層餐飲勞工名目薪資直接調升
  • 刺激大眾外食與民生消費總需求
名目薪資 ($W$) 同步增長
最終結果: 淨購買力拉鋸

實質購買力 ($\text{Real Wage} = W/P$)

  • 若 $\Delta W / W > \Delta P_{out} / P_{out}$：購買力淨提升
  • 若通膨轉嫁速度過快：名目薪資增幅被抵銷
  • 呈現具時間滯後（Lagged）之非線性關係

import pandas as pd
import numpy as np
import statsmodels.api as sm
from statsmodels.tsa.api import VAR

def load_and_clean_data(filepath):
    # 1. 讀取 AREMOS 匯出之 CSV 檔案
    df = pd.read_csv(filepath)
    df['Date'] = pd.to_datetime(df['Date'], format='%Y/%m')
    df.set_index('Date', inplace=True)
    
    # 2. 處理缺漏值與建立實質經常性薪資 (Real Wage)
    df.ffill(inplace=True)
    df['Real_Wage'] = (df['WA_HOTEL_CATER'] / df['CPI_TOTAL']) * 100
    
    # 3. 計算各關鍵變數之年增率 (YoY, %)
    df['MW_YoY'] = df['MW_MONTH'].pct_change(12) * 100
    df['CPI_Food_YoY'] = df['CPI_FOOD_OUT'].pct_change(12) * 100
    df['Real_Wage_YoY'] = df['Real_Wage'].pct_change(12) * 100
    
    return df.dropna()

def run_ols_regression(df, lag_p=2):
    # 建立帶滯後期之基本工資變數
    df[f'MW_YoY_lag_{lag_p}'] = df['MW_YoY'].shift(lag_p)
    
    X = df[['MW_YoY', f'MW_YoY_lag_{lag_p}', 'IPI_AGRI_RAW']].dropna()
    Y = df['CPI_Food_YoY'].loc[X.index]
    
    X = sm.add_constant(X)
    model = sm.OLS(Y, X).fit()
    return model

def run_var_analysis(df):
    var_data = df[['MW_YoY', 'CPI_Food_YoY', 'Real_Wage_YoY']].dropna()
    model = VAR(var_data)
    results = model.fit(maxlags=2)
    irf = results.irf(12)
    return irf
